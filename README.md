# Ensemble Learning Techniques

This project implements ensemble learning techniques using Python and Scikit-learn.

- Implements Stacking, AdaBoost, and Voting Classifier.
- Uses Logistic Regression, Decision Tree, and KNN as base classifiers.
- Evaluates models using accuracy, precision, recall, and F1-score.
- Compares individual classifiers with ensemble models.
- Displays a chart to compare model accuracy.
